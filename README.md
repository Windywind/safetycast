# 课堂安全播报助手 MVP

Windows 桌面驻留的 1530 安全教育自动播报工具（单机离线版）。

## 运行环境

- **操作系统**：Windows 10/11（64 位）
- **Python**：3.8+（推荐 3.10-3.13），需从 [python.org](https://python.org) 安装，安装时勾选 "Add Python to PATH"
- **无需联网**：全离线运行，仅在首次安装依赖时需要联网

## 快速开始

### 首次使用（安装依赖）

1. 确认系统已安装 Python 并加入 PATH。
2. 双击 `script/setup.bat`，等待依赖安装完成。

### 日常启动

1. 双击 `script/start.bat` 启动（后台运行，看托盘区红黄图标）。
2. **图标可能被 Win11 收进隐藏图标区**：点任务栏右下角的 **∧（向上箭头）**，在展开区里找红底黄心的图标。
3. 右键托盘图标可"立即试播"三种提醒（左键/双击图标不触发任何动作，防误触）：
   - 每日 1 分钟提醒（红底大字 + 语音朗读）
   - 周五 5 分钟专题
   - 节假日 30 分钟专题
4. 右键菜单还有 **"设置…"**，打开设置窗口调整放学时间、播报规则、假期列表、弹窗字号、语音音色/语速/音量，**保存即生效、无需重启**（详见下方「设置界面」）。

> 启动脚本会自动检测 Python：优先使用项目内 `.venv`（若存在），否则使用系统 Python。无需手动指定路径。

## 排障

- 看不到图标：检查 `log/debug.log` 最后一行是否为"托盘对象已创建，开始 run()"；没有则说明启动失败（会弹错误框）。
- 确认进程：任务管理器里应有 `pythonw.exe`；若启动失败，`script/start_debug.bat` 会显示错误弹窗。
- 托盘实现：`tray_win.py`（纯 Win32 API，不依赖 pystray，兼容 Python 3.13/Win11）。

## 自动播报规则（config.json）

- 放学时间：`dismissal_time`（默认 16:30）
- 每日：放学前 1 分钟（按星期轮换内容）
- 周五：放学前 5 分钟
- 节假日：假期前最后一个教学日，放学前 30 分钟（在 `upcoming_holidays` 里配置假期日期，格式 `YYYY-MM-DD`）

## 设置界面

右键托盘图标 → **"设置…"** 打开设置窗口（纯 Windows 原生对话框，无需联网）。改完点 **"保存并生效"** 立即生效，**不用重启程序**。

窗口内按功能分为 5 组，右侧带滚动条（适配 100%~200% 缩放），底部"保存并生效 / 取消 / 恢复默认"三个按钮固定不滚动：

| 分组 | 可调项 |
|------|--------|
| 放学时间 | `HH:MM`（00:00~23:59） |
| 播报规则 | 每日 / 周五 / 节假日 三行，各含「启用」勾选、提前分钟数（0~120）、弹窗标题（≤30 字） |
| 假期列表 | 多行文本，每行一个 `YYYY-MM-DD`，可整学期批量粘贴 |
| 弹窗样式 | 字号档位（90/100/115/130/150%）、最短停留秒数（5~300） |
| 语音 | 音色、语速档位、音量档位，附 **试听** 按钮 |

要点：

- **音色**：下拉框列出本机已安装的系统语音（如 Huihui、Kangkang），首项为「系统默认」。若配置里记录的音色在换机器后不存在，程序会**自动回退默认音色**，不报错、不静音（`log/debug.log` 会记一行）。
- **试听**：用当前表单里**尚未保存**的语速/音量/音色念一句真实播报内容，改完当场验证。试听可随时「停止」；若此刻正在正式播报，试听按钮会提示「播报进行中」并拒绝，二者互不干扰。
- **保存即热生效**：落盘 → 内存配置原地更新 → 调度器最坏 15 秒内重算下次播报时间 → 弹窗字号与语音参数下次播报即采用新值。保存前会自动备份 `config.json.bak`，写盘为原子操作（写临时文件再替换），不会写坏配置。
- **校验**：保存前逐项校验，任一项不合法会弹出中文提示（指明哪一项、错在哪、允许范围），且**不写盘**、窗口保持打开并聚焦到出错控件，已填内容保留供修正。
- **恢复默认**：把表单恢复为出厂值，但需再点「保存并生效」才落盘。
- 同一时刻只允许一个设置窗口；窗口开着时再次点「设置…」会激活已有窗口而非新开。

> 服务端地址等 V1.0 功能暂未纳入本设置界面。开机自启已支持（「启动」分组勾选，写 HKCU Run 键）；CSV 台账记录已支持（自动落 log/broadcast_log.csv），绑定班级属 V1.0。

## 说明与限制

- 弹窗全屏红底置顶、朗读完自动关闭，也可点屏幕或按 ESC 关闭。
- 全离线运行，不联网。
- MVP 限制：无远程推送、无服务端地址配置（V1.0 内网服务端尚未开发）。设置界面已支持放学时间/规则/假期/字号/语音/开机自启的可视化修改并保存即生效。
- 后续路线：P0 DPI自适应（已完成）→ P1 设置界面（已完成）→ P2 开机自启（已完成）/CSV台账记录（已完成）→ P3 exe打包 → V1.0 内网REST服务端。详见 `docs/课堂安全播报助手-PRD.md` 第8章。

## 交付部署

**方式 A：exe 绿色包（推荐，目标机无需 Python）**

1. 在本机双击 `script/build_exe.bat`（首次会自动安装 PyInstaller）。
2. 把生成的 `dist/SafetyCast.exe`（**单个文件**，约 7MB）拷到目标机器任意位置。
3. 双击运行；`config.json` / 播报台账 / 日志统一存放在
   `%APPDATA%\SafetyCast\`（exe 放 Program Files 等受保护目录也照常可写）。
   旧版本放在 exe 旁的数据会在首次运行时自动迁移过去。开机自启在设置里勾选即可。
   想换托盘图标，把自定义 `app.ico` 放到 exe 旁即可（不放则用内嵌默认图标）。

> 单文件模式启动比文件夹模式慢 1~3 秒（每次自解压到临时目录），属正常。

**方式 B：源码运行**

1. 将整个项目文件夹拷贝到目标机器。
2. 确认目标机器已安装 Python（3.8+），并加入了系统 PATH。
3. 双击 `script/setup.bat` 安装依赖。
4. 双击 `script/start.bat` 启动程序。

> 若目标机器有 `.venv`，启动脚本会优先使用它；没有则自动使用系统 Python，无需额外配置。
